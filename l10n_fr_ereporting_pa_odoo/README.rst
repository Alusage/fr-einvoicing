Glue module between ``l10n_fr_ereporting`` and
``l10n_fr_einvoicing_pa_odoo``, installed automatically when both are.

When a company sends and receives through the Odoo accredited platform,
its e-reporting flows (flux 10) are carried by that platform, so their
sender block (TT-7 to TT-11) names the Odoo platform instead of the
accredited platform selected for the directory.
